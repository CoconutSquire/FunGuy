# Legacy roster placeholder import

The legacy roster at `FunGuy's/Assets/_Game/Resources/GameData/funguy_characters.json` is now imported during `GameData.LoadAll`.

`LegacyCharacterImporter` converts only IDs missing from the current `characters.json` catalog. Existing authored IDs remain authoritative, so saves and their current kits are not replaced. Imported entries receive the existing executable placeholder basic/signature skills and the existing `FungusPortrait` presentation automatically.

The placeholder portrait is generated by `FungusPortrait` and selected in the existing battle and workshop views from biome and class. No per-character sprite files are required. Imported characters therefore appear in data-backed roster/upgrade views and can render in battle once owned and placed in a team.

Validation was not run in this API session. The next local check should run the Unity EditMode suite and a Team → Battle smoke test with an imported ID not present in `characters.json`.
